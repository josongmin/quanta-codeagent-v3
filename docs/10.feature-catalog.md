# 10. 기능 카탈로그 (Feature Catalog)

quanta-codeagent-v3에 **구현·배선된** 기능 전수 목록. **대**(주요 시스템) → **중**(하위 능력) → **소**(구체 기능/노브) 3단.

근거: RFC `rfc/0001-architecture.md`, ADR `docs/decisions/0001~0027`. cross-import는 `@/agent`만(슬라이스 격리). 운영 reference: [docs/runbooks/agent-loop-reference.md](docs/runbooks/agent-loop-reference.md).

Round 3-5 critical-review 후속(2026-05-20): 외부 비평 라운드(P1 security + structural FU + Round 5 cleanup)로 (a) WorkingState `snapshot()` deep-copy 강화, (b) `MUTATING_MODES` 인버스 (fail-closed), (c) `inferToolTier` 기본 fallback `always-confirm`, (d) `applyScriptedReplaceBounded` 제거(security theater 회수), (e) `update_working_state` 문자열 캡(`MAX_STR=500`/`MAX_HYPOTHESIS=2000`) + empty-patch refine, (f) `HARD_DENY` `RegExp[]` → `HardDenyRule[]` 명명 카탈로그(16개) + 144 per-rule 단위, (g) `ToolResult.evidence` 타입 필드(`stderr/exitCode/fullLogPath`)로 duck-typed smuggling 제거, (h) `EditMismatchKind` 리터럴 union + `Record<>` exhaustiveness 컴파일 게이트, (i) `BlockerSurface` 타입 union + cross-slice mirror 컴파일 가드, (j) Closeout-guard precedence(explicit fourRule > code-mod 자동감지 > legacy), (k) subagent `mode/verifyGuard/closeoutGuard/hitl` 전파, (l) registry spill → `evidence.fullLogPath` 라우팅, (m) 시스템 프롬프트 cargo prune(compaction-note 단락 제거 / OWASP 한 줄 압축). 신규 ADR 번호는 없으며 0011~0027 contract 하 hardening(주석/테스트로 의도 명시).

## 성숙도 5단계 척도

있다/없다 이분이 아니라 **구현 폐쇄도(closure)** 를 5단계로:

| 등급 | 의미 |
|---|---|
| **L5 ●●●●●** | 완성·검증 — 구현·배선·단위+통합테스트, **실 LLM 스모크 또는 e2e 폐쇄** 확인됨 |
| **L4 ●●●●○** | 견고 — 구현·배선·단위+통합테스트(실 runAgent, mock LLM). 실 LLM 스모크는 미실시 |
| **L3 ●●●○○** | 동작 — 구현·배선됨, **단위테스트 위주**(통합 미검증) |
| **L2 ●●○○○** | 부분/한계 — 동작하나 **의도적 제약·advisory·옵셔널 미도달** |
| **L1 ●○○○○** | 골격/보류 — **타입/API만 노출**, 루프 미배선, 의식적 후속 |

`⚙️` = env/config 노브(기본 OFF·behavior-preserving). 검증 베이스라인(2026-05-20, Round 3-5 후속): tsc `--noEmit` 0 · 1792 pass / 0 fail / 4 skip / 4827 expect() across 124 files (93 unit + 28 integration + 3 contract). contract 스위트(`tests/contract/`)는 `REQUIRE_CONTRACT` 미설정 시 미설치 환경에서 자동 skip(`_guard.ts`); 설정 시 loud-fail.
