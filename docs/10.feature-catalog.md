# 10. 기능 카탈로그 (Feature Catalog)

quanta-codeagent-v3에 **구현·배선된** 기능 전수 목록. **대**(주요 시스템) → **중**(하위 능력) → **소**(구체 기능/노브) 3단.

근거: RFC `rfc/0001-architecture.md`, ADR `docs/decisions/0001~0014`. cross-import는 `@/agent`만(슬라이스 격리).

## 성숙도 5단계 척도

있다/없다 이분이 아니라 **구현 폐쇄도(closure)** 를 5단계로:

| 등급 | 의미 |
|---|---|
| **L5 ●●●●●** | 완성·검증 — 구현·배선·단위+통합테스트, **실 LLM 스모크 또는 e2e 폐쇄** 확인됨 |
| **L4 ●●●●○** | 견고 — 구현·배선·단위+통합테스트(실 runAgent, mock LLM). 실 LLM 스모크는 미실시 |
| **L3 ●●●○○** | 동작 — 구현·배선됨, **단위테스트 위주**(통합 미검증) |
| **L2 ●●○○○** | 부분/한계 — 동작하나 **의도적 제약·advisory·옵셔널 미도달** |
| **L1 ●○○○○** | 골격/보류 — **타입/API만 노출**, 루프 미배선, 의식적 후속 |

`⚙️` = env/config 노브(기본 OFF·behavior-preserving). 검증 베이스라인(2026-05-20): tsc 0 · Biome 0/0 (228+ files) · unit + integration 전 green.

## 대 1. 에이전트 코어 루프 (ReAct) — `src/agent/loop.ts` · ADR-0004/0011

| 중 | 소 | 등급 |
|---|---|---|
| 1.1 턴 상태머신 | 단일 `while` 루프, FSM weight 없음 | **L5** |

| | 종료사유 `completed\|max_turns\|aborted\|error`, AbortSignal 협조취소 | **L5** |
| 1.2 Same-turn 복구 | transient backoff / PTL→compact / max_tokens / malformed / empty | **L5** |
| 1.3 스트리밍 도구 실행 | safe 도구 스트림 중 즉시 디스패치, 순서보존, head-of-line 배리어 | **L5** |
| | `stream_reset` tombstone(fallback 시 in-flight 폐기) | **L4** |
| | nudge/completed 전 디스패치된 read-only 결과 폐기(read-only라 안전, 코드 문서화) | **L4** |
| 1.4 Verify-guard (Tier 0) · ADR-0013 | 변경 도구 후 검증 없이 finish 시도 → 1턴 강제(maxTrips cap, 기본 1). best-effort 게이트. 실측 0트립 (Easy-5 gpt-4o) — best-effort, empirically inert on this agent/model | **L4** |
| | 검증 인정: `test_runner` 항상 / `bash`는 test·repro 휴리스틱(`TEST_LIKE_RE`) 매칭 시만(평범 셸 불인정) | **L5** |

## 등급 분포 요약

- **L5**(완성·검증): 코어 루프·복구·스트리밍 디스패치, HARD_DENY, 압축 본체, retry, 캐시-prefix, 듀얼 provider, 아키텍처 정책, bench repair 순수정책
- **L4**(견고): verify-guard, 결과cap+spill, auto-classifier, breaker, summarizer, subagent, skill 본체+스코핑강제, fallback, 메모리, 관측성, plan, hooks, CLI, bench repair 통합
- **L3**(동작·통합미검): MCP, LSP, resume, 벤치, Docker 샌드박스
- **L2**(부분/한계): `ToolSearch`(어휘검색), skill model/effort scoping(advisory), CLI export-gap
- **L1**(보류): skill `paths:` 자동활성(API만 노출)
