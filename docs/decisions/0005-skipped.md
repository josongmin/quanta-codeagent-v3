# ADR-0005: (의도적 결번)

- **상태**: Skipped
- **날짜**: 2026-05-19
- **관련**: RFC-0001 §9(ADR 정책)

## 결정

ADR-0005 번호는 사용하지 않는다. 시퀀스는 0004 → 0006으로 건너뛴다.

## 근거

ADR 번호는 단조 증가하는 식별자일 뿐이며, 기록할 만한 결정이 그 시점에
없었다(RFC §9.1 "코드 동작 후 작성 — 가설 ADR 금지"). 비어 있는 0005를
사후에 채워 넣는 것은 가설 ADR이 되므로, git/RFC 어디에도 0005가 무엇이었는지
근거가 없다는 사실을 그대로 기록하는 것이 정직하다. 번호를 재사용하면 기존
상호참조(0006~0009)가 흔들리므로 결번을 고정한다.

## 트레이드오프

- **얻은 것**: 번호 연속성 착시 제거. 향후 독자가 "0005 유실"로 오해하지 않음.
- **잃은 것 / 비용**: placeholder 파일 1개. 무시 가능.
