# Completion reports

Create one file per completed ticket: `SNC-XX.md`.

```md
# SNC-XX completion receipt

- baseline HEAD:
- final HEAD:
- files changed:
- owner seam:
- RED before implementation:
- focused proofs and exit codes:
- broad proofs and exit codes:
- unrelated RED:
- residual risk:
- next unblocked ticket:
```

Do not write `done` without command evidence. Historical green is not current green.
