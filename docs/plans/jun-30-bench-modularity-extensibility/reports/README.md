# Reports

Add one report per completed ticket:

- filename: `YYYY-MM-DD-T{n}-closeout.md`
- example: `2026-06-30-T1-closeout.md`

## Required sections

1. `Scope`
2. `Baseline`
3. `Files changed`
4. `Proof rails run`
5. `Bench-owned result`
6. `Surrounding unrelated red`
7. `Remaining follow-up`

## Required discipline

- split bench-owned closure from unrelated repo-global red
- name any live-only or non-hermetic proof gap explicitly
- include the exact commands run
