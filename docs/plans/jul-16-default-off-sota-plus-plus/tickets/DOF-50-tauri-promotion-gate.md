# DOF-50 - external and platform holds

**Priority:** P2  
**Depends on:** DOF-10 for Tauri only

Track Tauri, Windows sandbox helper, TLS MITM CA lifecycle, Mantle SDK, token rotator, and other external/platform blockers separately. A hold is not a failed feature and is excluded from the eligible denominator only with a named external prerequisite and recheck command.

Tauri promotion requires reproducible build, launch, daemon connection, auth, and one operator flow. Web success alone is not desktop proof.
