## 의도적 미흡수 (제품/운영/실험 인프라 — ADR-0011 근거)

백그라운드 데몬 · Statsig 원격게이트/kill-switch · Datadog+cohort 텔레메트리 · full speculative-prompt-execution

> 이전 라운드에서 보류했던 항목(예: `update_working_state` per-string 캡 / empty-patch refine / `ToolResult.evidence` 평면화 / HARD_DENY rule 명명화 / `inferToolTier` secure-by-default / `MUTATING_MODES` 인버스 / `applyScriptedReplaceBounded` 회수 / 시스템 프롬프트 cargo prune)은 후속 라운드에서 해소되어 상기 features 표에 반영됨. 변동 이력은 git log 참조.
